# C++ / CUDA 版与 Python 版对比

- 日期 2026-11-28；代码基线 `9d5bc35` + `cpp/`（未提交时测量）
- RTX 4060（驱动 595.58.03）、CUDA 12.8、TensorRT 10.13.3、OpenCV 5.1.0、g++ 13.3、12 核；Python 侧 PyTorch 2.10、Triton 3.6.0
- 默认生产配置：opt 模式、official 尺寸、exact profiles；两边都不编码预览（`--no-preview`）
- 复现：`cpp/bench.sh`（结果 JSON 在本目录，`op/` 由 `--op-times` 得到）

## 1080p 端到端（3 轮交错 x 150 帧）

| 版本 | ms/帧（中位数，三轮） | p95 | 启动到首帧 | 主机内存峰值 | 显存峰值 |
|---|---|---|---|---|---|
| Python | 139.3（139.0 / 139.4 / 139.4） | 142.5 | 9.43 s | 2408 MB | 1098 MB |
| C++ cuda | 136.0（135.8 / 136.0 / 136.1） | 139.6 | 2.64 s | 958 MB | 1052 MB |
| C++ tex_point | 136.0（135.7 / 136.2 / 136.1） | 139.5 | 2.65 s | 960 MB | 1052 MB |
| C++ tex_linear | 137.3（137.2 / 137.3 / 137.4） | 140.5 | 2.65 s | 960 MB | 1096 MB |

画中画（各 1 轮 x 150 帧，Python / cuda / tex_point / tex_linear）：frame 139.5 / 136.1 / 136.0 / 137.7；icon 139.6 / 136.2 / 135.9 / 136.8 ms。

## 时间花在哪里

GPU 上的 TensorRT 推理两眼合计约 126 ms，是关键路径；CPU 几何（SGBM 约 36～39 ms + DIS 光流约 56～59 ms）与它并行，被盖住。语言能影响的只有推理之外的约 10 ms。

分模块（`--profile`，模块前后同步设备，1080p）：

| 模块 | Python | C++ cuda |
|---|---|---|
| seg.model | 127.16 | 126.25 |
| seg.person | 4.75 | 2.52 |
| gpu.post | 2.91 | 1.69 |
| gpu.compose+d2h | 1.38 | 1.33 |
| gpu.upload_frame | 2.15 | 2.57 |

端到端省下的 3.3 ms 与 seg.person + gpu.post 的差（3.45 ms）相当。推测来自 Python 侧逐算子的分发与下发开销（短 kernel 之间 GPU 空闲），没有用 nsys 验证。启动时间的差距推测主要是 import 和构建 torch 模型，未单独计时。

- tex_point 与 cuda 基本持平（缩放慢 18%），tex_linear 没有一个算子更快，box、缩放、画中画 frame（每帧整图转 BGRA）明显更慢。因此默认用 cuda，没有加混合组合（`--kernel best`）。
- tex_linear 端到端慢 1.3 ms，主要出现在 TensorRT 这一段（+1.2 ms），原因未查明。
- 表中只有 person、box、warp、compose、resize 有纹理版，其余逐点算子的三列只是重复测量。

## 正确性

逐阶段（`tools/dump_ref.py` + `tools/compare.py`，6 帧；cuda 在 1920x1080、1440x1080、854x480、640x480 上）：

- 灰度、视差、光流、TensorRT logits / masks、hard mask、disparity fill：逐位相同
- 模型输入：差 ≤ 2.4e-7（归一化舍入）；person prob ≤ 1.7e-6；alpha ≤ 2.1e-5；合成图最多 1 灰度级（≤ 0.03% 像素）
- tex_point（1080p，及画中画合成图）与 cuda 结果相同
- tex_linear（1080p）：模型输入最多差 1 灰度级，经网络放大后 person prob 最大 0.127、alpha 最大 0.119（平均 5.5e-5）；画中画合成图最多差 37（icon）

## 候选（未做）

- 推理（126 / 136 ms）是唯一的大头：需要换更小的 backbone、降精度或改尺寸策略，超出本次范围。
- tex_linear 的 TensorRT 段变慢原因未查。
- C++ 的 `gpu.upload_frame`（单线程逐行 memcpy）比 Python 慢 0.4 ms，可改为多线程或让解码直接写入 pinned buffer。
